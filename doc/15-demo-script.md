# 15 · 演示脚本（约 4–5 分钟）

> 目标：赛题五能力一次讲清——资料理解 / 规则匹配 / 风险提示 / 投研整理 / 流程辅助。  
> 默认模式：`BIZATLAS_MODE=snapshot`（无外网 API 也可演示）。

---

## 0. 开场（20 秒）

**口播：**  
「商舆不是通用聊天套壳，而是 **数据 + 规则 + 计算** 的企业经营风险研判 Agent。关键数字走确定性计算，结论可溯源，人在回路。」

打开：http://127.0.0.1:5173（或 5174）  
确认顶栏：`mode snapshot` · `rules 22` · `DB OK`

---

## 1. 资料理解（60 秒）

### 路径 A（推荐·更快）
1. 切到 **上传 CSV/PDF**  
2. 上传 `content/templates/sample_financial_excerpt.pdf`（或 `.txt` / `metrics_template.csv`）  
3. 展示：解析指标数、来源文件名  

**口播：**「上传财报摘要或指标表，自动抽取流动比率、资产负债率等关键指标；PDF 走文本抽取，CSV 走结构化模板。」

### 路径 B（无上传）
直接用演示案例 `risky`。

---

## 2. 规则匹配 + 风险提示（90 秒）

1. 点击 **帮我看风险**（或贷前流程里的「研判」）  
2. 指出：  
   - 一句话结论 + **等级徽章**（risky≈RED）  
   - **五维雷达图**  
   - 命中列表：规则 ID、条件 vs 实际值（可解释）  
3. 切案例 `defaulted` 再跑一次 → **BLACK**（失信一票否决）

**口播：**「规则外置 YAML，命中可审计；失信等事件可一票否决到 BLACK，不是模型随口打分。」

---

## 3. 投研整理 + 溯源（60 秒）

1. 点 **一页摘要** → Markdown 预览  
2. 点 **导出摘要 Word/MD** 或 **导出信用报告 Word** → 落盘 `exports/*`（人在回路）  
3. 点一条规则命中 → 打开 **溯源抽屉**（指标 / 来源 / tier）  
4. 展示 **担保链图谱**（risky / defaulted 含 `graph.json`）

**口播：**「报告插槽数字来自计算结果；导出必须确认；命中可点开追溯到指标与来源。」

---

## 3b. 差异化加分（60–90 秒）

1. **五维归因**：点雷达维度或归因 Tab → 驱动指标 + 命中规则  
2. **多源冲突**：risky 展示资产负债率/商誉等跨源 Δ（不擅自裁定）  
3. **行业对标**：传统建材 L3 静态中位 vs 企业值  
4. **压力测试**：营收承压 / 利率冲击 / 担保链传染三情景  
5. **G6 图谱**：拖拽缩放担保链  
6. 顶栏进 **规则中心**（NL 加规则）· **报告中心**（导出 Word/PDF）  
7. 副驾：问「客户集中度多少」→ 本地 RAG 摘录  

**口播：**「不是聊天套壳——冲突可见、压力可算、归因可下钻、规则可演化。」

---

## 4. 流程辅助（60 秒）

1. 切到 **贷前尽调**  
2. 选 `risky` → **启动贷前尽调**  
3. 展示资料清单齐套  
4. **研判 → 出报告 → 确认提交**  
5. 展示阶段条：清单→齐套→研判→复核→已提交  

**口播：**「把分析嵌进贷前工作流：缺料会挡住，高风险提交必须人工确认。」

---

## 5. 收尾差异化（30 秒）

**口播三点：**  
1. 数字零幻觉（计算管线）  
2. 规则可演化、可解释  
3. 资料可不出域（snapshot / 本地 SQLite）  

数据源（Tushare/天眼查等）已留占位，可按机构密钥逐个点亮。

---

## 备用话术

| 评委问 | 答 |
|---|---|
| 和直接问大模型有何区别？ | 指标与评分强制计算；LLM 只做文案/NL 规则辅助 |
| PDF 扫描件怎么办？ | 现支持文本型 PDF；扫描件后续 OCR，CSV 模板兜底 |
| 数据从哪来？ | 上传为主；AKShare/Tushare/工商 API 占位可配 |
