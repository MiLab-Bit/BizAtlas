# ADR-003 · 三级降级，分析不中断

## 状态

已接受 · 2026-08-06

## 背景

外部数据源限流、内网无网、解析部分失败在真实与答辩场景均常见。

## 决策

1. 采用 L1 实时 → L2 缓存 → L3 估算，字段级 `_tier`。  
2. 运行模式 `snapshot | hybrid | live`（`BIZATLAS_MODE`）。答辩默认 **snapshot**。  
3. 单字段失败不得导致整个 Analyze 任务 abort；最多 `failed_partial`。  
4. UI/报告必须展示降级比例与清单。

## 后果

- Provider 必须实现统一接口与 health。  
- 评分在数据缺失时对缺失维度标注，而非静默当成 0（除非规则显式定义）。
