# ADR-001 · 关键数字强制走计算

## 状态

已接受 · 2026-08-06

## 背景

通用 LLM 易在财报数字上幻觉。赛题与金融机构均要求可审计、可复核。

## 决策

1. 报告 / UI 中的**关键财务数字与风险分数**必须来自 `ingest` 抽取或 `risk` 计算管线。  
2. LLM 仅用于：版面理解辅助、NL 规则编译、叙述润色。  
3. 润色输出经 **Number Gate**：出现未在 `MetricPack`/`RiskResult` 登记的数字则拒绝，回退模板句。

## 后果

- 实现成本：需要插槽装配与 Gate。  
- 收益：QG-1 可强制执行；评委问题「和直接问大模型有何区别」有工程答案。
