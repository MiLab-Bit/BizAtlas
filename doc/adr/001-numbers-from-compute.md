# ADR-001 · 关键数字强制走计算

## 状态

已接受 · 2026-08-06

## 背景

通用 LLM 易在财报数字上幻觉。赛题与金融机构均要求可审计、可复核。

## 决策

1. 报告 / UI 中的**关键财务数字与风险分数**必须来自 `ingest` 抽取或 `risk` 计算管线。  
2. LLM 仅用于：版面理解辅助、NL 规则编译、叙述润色。  
3. 润色输出经 **Number Gate**：未在 `MetricPack`/`RiskResult` 登记的数字（"可疑数字"）数量 **≤ 2** 时，就地标注 `[待核验]` 后予以保留；**超过 2 个**才拒绝整段、回退模板句。
   > 阈值口径以 `bizatlas/llm/number_gate.py::gate_or_fallback` 实现为准（当前常量为 `2`）。
   > 2026-10-05 起实现由"任一未登记即拒绝"放宽为上述"少量标注保留"，本 ADR 据此与实现对齐。

## 后果

- 实现成本：需要插槽装配与 Gate。  
- 收益：QG-1 可强制执行；评委问题「和直接问大模型有何区别」有工程答案。
- 取舍（2026-10-05）：阈值放宽后，单段≤2 个可疑数字不再被丢弃，而带 `[待核验]` 标注保留——以"可标注"换"少浪费 LLM 输出"；>2 个仍整段回退，兜住幻觉风险。
