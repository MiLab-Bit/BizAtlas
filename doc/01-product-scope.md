# 01 · 产品范围（工程视角）

> 对齐 PRD：`01_产品定位与愿景` · `09_路线图与MVP`  
> 本文件把产品愿景收敛为可编码的边界。

---

## 1. 一句话

**BizAtlas** 实现商舆：上传企业资料 → 抽取指标 → 规则匹配 → 五维风险评分 → 一键报告，全程可解释、可降级、人在回路。

---

## 2. MVP 必做（Phase 1 / 参赛核心）

| ID | 能力 | 验收（来自 PRD） |
|---|---|---|
| M1 | 资料理解 | 标准 PDF/Excel 财报三表解析；关键指标准确率 ≥ 90%；问答带引用 |
| M2 | 规则匹配 | 内置 ≥ 20 条规则（财务红线 + 基础合规）；NL 新增 → Schema → 入库；命中可解释 |
| M3 | 风险提示 | 五维评分 + GREEN–BLACK 等级 + 一页风险摘要 |
| M4 | 投研整理 | 一键生成企业信用评估报告；Word / PDF 导出 |
| M5 | 流程辅助 | 贷前尽调模板：资料清单 → 研判 → 报告；全流程演示 < 5 分钟 |

### 标杆案例（演示固定）

| 案例 | 类型 | 展示点 |
|---|---|---|
| A 健康企业 | 制造业 | GREEN/YELLOW，指标正常 |
| B 风险企业 | 传统行业 | ORANGE/RED，多规则命中 |
| C 违约企业 | 历史样本 | BLACK，事后验证「当时该发现」 |

---

## 3. Non-goals（明确不做）

| 不做 | 原因 |
|---|---|
| 买卖建议 / 替代最终授信决策 | 商业边界；人在回路 |
| 对接交易 / 资金系统 | 仅分析与辅助 |
| 个人信贷 | 专注企业 / 对公 |
| 未标注的数据推断 | 缺失必须降级标注 |
| MVP 批量监测、深度归因、行内系统集成 | P1/P2，见路线图 |
| MVP 引入图数据库 | NetworkX + JSON 足够 |

---

## 4. 不可砍需求（Quality Gates）

| 门禁 | 说明 |
|---|---|
| QG-1 数字零幻觉 | 报告中的关键财务数字必须来自抽取/计算管线，禁止 LLM 直接生成数字 |
| QG-2 可溯源 | 每条结论可跳到「指标值 + 规则 ID + 数据来源（文件/页码/API）」 |
| QG-3 降级可见 | `_tier` ∈ {L1,L2,L3} 在 UI 与报告中显式展示 |
| QG-4 人在回路 | 规则命中只提示；导出/提交流程需用户确认 |
| QG-5 私有化路径 | 上传资料默认可本地存储；RAG 不出域 |

---

## 5. 用户与主路径（工程切片）

主用户：银行对公客户经理 / 风控经理（详见 PRD 02）。

主路径（唯一优先打通）：

```
上传财报 → 自动解析 → 「帮我看风险」→ 雷达+命中清单 → 一键报告 → 人工复核
```

对话与页面双向联动；MVP 对话入口可简化为 Streamlit 聊天框 + 固定快捷指令。

---

## 6. 成功指标（工程可测）

- 闭环演示 < 5 分钟，五项能力均可展示。
- 关键指标抽取准确率 ≥ 90%（以 fixtures 标注集为准）。
- 规则命中测试：种子规则集通过率 100%。
- 数据源失败时流程不中断，报告含降级说明。
