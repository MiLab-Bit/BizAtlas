# 13 · 功能与特色（产品→工程）

> 对齐 PRD `01`·`03`·`10` · 范围见 [`01-product-scope.md`](./01-product-scope.md)  
> 数据 API 占位见 [`../content/providers/registry.yaml`](../content/providers/registry.yaml)，**先做功能，密钥稍后逐个点亮**。

---

## 1. 一句话

**商舆 = 读懂资料 → 按规则研判 → 五维风险可视化 → 一键报告 → 贷前流程辅助**
特色不是「又能聊」，而是 **数据 + 规则 + 计算** 可解释、可降级、人在回路。

---

## 2. 五大功能（赛题对齐 · MVP 必做）

### F1 资料理解

| 项 | 内容 |
|---|---|
| 做什么 | 上传财报/公告等，抽三表与关键指标；本地问答带引用 |
| 用户感知 | 拖入 PDF → 指标卡 +「最大客户占比？」可答且跳页码 |
| 特色点 | **多源冲突标注**（不擅自裁定）；关键数字不靠 LLM 编造 |
| 数据依赖 | 上传为主；API 仅补全（占位：akshare/tushare/cninfo） |
| 验收 | 指标准确率 ≥ 90%；问答有 citation |

### F2 规则匹配

| 项 | 内容 |
|---|---|
| 做什么 | ≥20 条种子规则扫描；自然语言加规则；命中可解释 |
| 用户感知 | 「商誉占比超 30% 预警」→ 入库 pilot → 确认后计分 |
| 特色点 | **规则外置 YAML + 版本化**；每条命中展示「条件 vs 实际值」 |
| 数据依赖 | 只要有 MetricPack / 事件布尔即可 |
| 验收 | 种子规则单测全过；NL→Schema 校验失败可读 |

### F3 风险提示

| 项 | 内容 |
|---|---|
| 做什么 | 五维评分、GREEN–BLACK、一页摘要、Top 风险点 |
| 用户感知 | 结论先行：「建议谨慎——担保链末端被执行」+ 雷达 |
| 特色点 | **量化评分 + 一票否决**；隐性关联（担保链）作记忆点 |
| 数据依赖 | 财务/经营靠上传；司法/关联 P0 用 fixtures，P1 点亮工商 API |
| 验收 | 三案例等级可区分；每维可下钻依据 |

### F4 投研整理

| 项 | 内容 |
|---|---|
| 做什么 | 一键信用评估报告 + 一页风险摘要；Word/PDF 导出 |
| 用户感知 | 插槽填数 → 润色叙述 → 人工确认导出 |
| 特色点 | **数字插槽锁定**（Number Gate）；附录含降级与引用清单 |
| 数据依赖 | 消费 RiskResult，不另接行情 |
| 验收 | 报告关键数字与评分页一致；导出需确认 |

### F5 流程辅助

| 项 | 内容 |
|---|---|
| 做什么 | 贷前尽调模板：资料清单 → 研判 → 报告 |
| 用户感知 | 向导勾选清单，缺料提示，齐套后一键跑 Analyze |
| 特色点 | **人在回路闸门**嵌在流程节点，不是事后补丁 |
| 数据依赖 | 弱；编排 F1–F4 |
| 验收 | Demo 全流程 < 5 分钟 |

## 3. 特色（和「套壳 ChatGPT」掰开的点）

| ID | 特色 | 一句话演示 | 工程落点 |
|---|---|---|---|
| D1 | **数字可溯源（计算确定性）** | 改提示词也改不出假营收 | ADR-001 · Number Gate |
| D2 | **处处可溯源** | 点风险点 → 规则 ID + 页码 | Evidence / SourceDrawer |
| D3 | **规则可演化** | 现场 NL 加一条并命中 | content/rules · pilot/activate |
| D4 | **五维量化 + 等级** | 雷达 + GREEN–BLACK 徽章 | packages/risk |
| D5 | **隐性关联风险** | 担保链 3 层末端被执行 | kg + 工商占位/fixtures |
| D6 | **三级降级可见** | 顶栏 L1/L2/L3 比例 | providers registry · `_tier` |
| D7 | **资料可不出域** | snapshot 无网完整演示 | fixtures · 本地 RAG · SQLite |
| D8 | **人在回路** | 导出/启规则必须确认 | HumanGate · API confirm |

宣传语（PRD）：  
> 把资深分析师读资料、算风险、写报告的功力，变成每个金融人的日常工具。

评委短答：  
**不是通用聊天，是「数据 + 规则 + 计算」底座；LLM 只做理解辅助与文案润色。**

## 5. MVP 演示脚本（功能视角）

```
1. 工作台打开案例 B（风险企业）或上传财报
2. Copilot：「帮我看风险」→ 进度 FSM → 结论 + 雷达 + Top 命中
3. 点一条命中 → 溯源抽屉（指标 / 规则 / 页码）
4. 规则中心：NL 加一条 pilot → 再跑匹配看见提示
5. 一键生成一页摘要 + 信用报告草稿 → 确认导出
6. （可选）贷前向导走一遍清单
```

全程强调 D1/D2/D6；有 fixtures 时亮 D5（担保链）。

---

## 6. 与数据占位的关系

- **功能不阻塞在 Key 上**：无 Tushare/天眼查时，F1–F5 用上传 + fixtures 全可演示。  
- **点亮 API 只增强**：同业对标更真、司法/股权从 mock → 真数。  
- 配置入口：`.env` + `content/providers/registry.yaml`（`enabled: false → true`）。

---

## 7. 非特色（故意不做的「伪功能」）

- 买卖点 / 荐股 / 替代信审终审  
- 实时行情大盘  
- 个人信贷评分  
- 无依据的「AI 综合印象分」
