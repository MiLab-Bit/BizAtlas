## 它到底解决什么问题

银行、投资、采购、监管，每天在做同一件事：**判断一家企业到底稳不稳、风险藏在哪里。**
但现实总卡在三件事上：

- **数据散** — 工商、司法、舆情、财务、供应链信号散在十几个来源，人工拼不出全景；
- **报告慢** — 一份尽调或贷前报告，资深分析师要熬好几天；
- **AI 不可信** — 通用大模型张口就来，结论没有出处，出错得你背锅。

商舆 BizAtlas 把这件事变成一句话触发：你给出企业（或股票代码），多智能体并行把上述信号抓回来、交叉验证、算出五维风险评分，并**每一条结论都附上原始数据出处**。你随时可以改、可以补充、可以加规则——**AI 算清楚，人做最终判断。**

## 品牌故事

**商舆** —— 「商」为商海，「舆」是舆图与舆情。古人以「舆图」指江山地形之全貌，以「舆情」听市井民心之起伏。**商舆，即替企业画出一幅风险地形图。**

**BizAtlas** —— Atlas 是古希腊神话中擎起苍天的巨人。我们要做的，是那个替你**擎起企业风险地图的巨人**：把庞杂、易碎、彼此矛盾的信号稳稳托住，交还你一张看得懂、信得过的图。

我们的核心立意很简单：**数字不可被幻觉辜负，AI 该算清楚，而不是侃侃而谈。**

## 核心能力（你拿到的成果，不是功能清单）

1. **一键风险画像** — 多智能体并行扫描，输出五维评分与一段人话写的风险摘要，几分钟替代几天。
2. **担保链与关联图谱** — 看清企业背后的关系网与风险如何传导，不被空壳公司绕晕。
3. **每一条结论都可溯源** — 结论锚定到原始数据节点，AI 不瞎编，出错你看得见。
4. **人在回路** — 你随时纠正、补充证据、写下规则；系统照你的口径持续运行。
5. **本地 RAG，数据不出域** — 私有规则与知识库本地检索增强，敏感信息不外传。

## 数据：全，而且验证过

风险研判最怕「数据不全」和「数据不准」。我们两端都做了硬保障：

- **接入全** — 9 路数据源、8 路就绪（工商 / 司法 / 舆情 / 财务 / 供应链 / AKShare / Tushare / 天眼查 / 新闻等），覆盖企业经营方方面面。
- **三级降级** — 某路挂了，自动用缓存 / 静态库 / 占位兜底，报告照出，绝不空窗。
- **六维质检** — 入库前做完整性、一致性、时效性、异常、去重、溯源六道校验。
- **本地 RAG 溯源** — 每条结论可回溯到原始抓取片段。
- **规则锚定** — 68 条研判规则（含 22 条种子规则）把结论钉在可验证的逻辑上。

## 工程与目录

技术栈：Python（FastAPI 后端）+ React / TypeScript（Vite 前端）+ 多智能体编排（agents / orchestrator），默认 SQLite，可接 Postgres。

```
BizAtlas/
├─ packages/bizatlas/   # 核心引擎：agents / orchestrator / data / rules / risk / rag / kg …
├─ apps/
│  ├─ api/              # FastAPI 服务（/v1/*，SSE 流式）
│  └─ web/              # React 工作台（数据源面板、风险图谱、报告中心）
├─ content/             # 规则与数据源占位（registry.yaml）
├─ deploy/              # 部署产物：Dockerfile / compose / systemd / nginx
├─ doc/                 # 产品设计、架构、数据层、API 契约等文档
└─ tests/               # pytest（154 passed）
```

部署与本地运行细节见 [`deploy/README.md`](deploy/README.md)。
